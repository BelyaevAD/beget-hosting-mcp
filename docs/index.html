Единый интерфейс для задач хостинга

Сервер сохраняет стандартный протокол MCP, но не скрывает устройство Beget API: методы можно находить, изучать и вызывать с явными параметрами.

01

Инструменты обнаруживаются автоматически

Cursor, Codex и другие MCP-клиенты получают список команд при подключении и могут искать нужный метод по встроенному каталогу.

02

Запись включается только явно

Изменяющие запросы требуют разрешения на уровне сервера и отдельного подтверждения в каждом вызове.

03

Документация работает локально

Репозиторий содержит Markdown-архив и структурированный индекс официальной документации, поэтому повторно сканировать сайт не требуется.

Быстрый старт

Установка без отдельной службы

Установите пакет, задайте отдельный API-пароль Beget и добавьте команду запуска в конфигурацию MCP-клиента.

Открыть инструкцию
terminal 
python -m pip install .
beget-hosting-mcp --list-tools

# Учетные данные отдельного API-пароля
BEGET_LOGIN=your-login
BEGET_API_PASSWORD=your-api-password

# Запись отключена по умолчанию
BEGET_ALLOW_WRITE=false

Предсказуемое управление

Оболочка добавляет проверки вокруг API, но результат операций все равно зависит от внешней инфраструктуры и не всегда виден мгновенно.

  • Отдельный API-пароль включается в панели Beget.
  • Изменения DNS распространяются с задержкой из-за TTL и кэширования.
  • Создание сайтов, почты и резервных копий может выполняться асинхронно.
  • Проверка результата не повторяет изменяющий запрос без явной необходимости.
